# 플러피뷰티 홈페이지 초안

김민선 원장님의 헤어스트로크·플러피브로우 랜딩페이지 검토본입니다. `index.html`을 열면 확인할 수 있습니다. 첫 화면은 기존의 둥근 영상 프레임과 따뜻한 세리프 제목으로 되돌리고, 아래는 긴 이야기처럼 읽히는 편집형 구성으로 만들었습니다. 플러피뷰티의 실제 사진·영상과 확인된 정보만 사용했습니다.

## 현재 연결된 주소

- 상담: [플러피 스튜디오 카카오채널](https://pf.kakao.com/_fGKin)
- 인스타그램: [@fluffy_pmu](https://www.instagram.com/fluffy_pmu/)

## 공개 전 교체·확인

1. 최종 상호 표기: 노션은 ‘플러피뷰티’, 카카오채널은 ‘플러피 스튜디오’로 표기됩니다.
2. 헤어스트로크 20만 원의 적용 기간·조건 및 포함 항목.
3. 제공받은 원장 프로필·시술 포트폴리오 사진의 최종 선택과 공개 동의.
4. 직접 예약 링크, 휴무일, 주차 안내.
5. 검토가 끝나면 `index.html`의 `noindex, nofollow`를 제거하고 공유 미리보기 이미지를 추가합니다.

첫 화면에는 바이브코딩 폴더의 AI 히어로 영상을 사용했습니다. 모바일 호환성을 위해 H.264 MP4로 변환하고, 자동 반복 재생·음소거·화면 내 재생·정지 이미지 대체를 설정했습니다. 영상 위의 작은 ‘AI 연출 영상’ 배지는 제거했고, AI 영상 사용 사실은 첫 화면의 세로 문구와 하단 문구에 남겼습니다. 원장 소개에는 2026년 10월 5일 제공받은 손을 얼굴에 대지 않은 프로필 사진을, 포트폴리오에는 실제 눈썹 사진을 사용했습니다. 영어 세리프는 Cormorant Garamond, 한국어 제목은 Noto Serif KR, 본문은 Inter/Noto Sans KR로 구성했습니다. 후기는 출처 자료가 없어 넣지 않았습니다.

눈썹 시술 사진 8장은 클릭하면 큰 이미지로 열리는 갤러리로 구성했습니다. 좌우 버튼·키보드 방향키·모바일 스와이프로 넘길 수 있습니다. 바이브코딩 폴더의 실제 시술 장면 1장과 매장 사진 3장도 추가했습니다. 화면에 들어오는 요소의 등장 효과는 움직임 줄이기 설정을 존중합니다.
원장 사진 바로 아래에 김민선 원장 이름을 강조하고, 원장 소개와 눈썹 갤러리 아래에 카카오 상담 버튼을 배치했습니다. 각 섹션의 제목·설명·사진은 스크롤에 맞춰 차분하게 나타납니다.
정지은 브로우 참고 사이트의 이야기형 화면 흐름을 참고해, 영상 → 첫 고민 → 실제 눈썹 사진 → 고객 고민 → 이벤트 → 원장 소개 → 상담 과정 → 전체 갤러리 → FAQ → 매장 → 상담 순서로 재구성했습니다. 헤어스트로크 20만 원 이벤트는 첫 화면, 중간 안내, 마지막 상담 영역에 보이며 적용 기간·조건과 포함 항목은 최종 확인 중이라고 표시했습니다. 홈페이지 공유는 섹션 해시 없이 첫 화면 주소로 합니다.
