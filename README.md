# 플러피뷰티 홈페이지 초안

김민선 원장님의 헤어스트록·플러피브로우 랜딩페이지 검토본입니다. `index.html`을 열면 확인할 수 있습니다. 첫 화면은 기존의 둥근 영상 프레임과 따뜻한 세리프 제목으로 되돌리고, 아래는 긴 이야기처럼 읽히는 편집형 구성으로 만들었습니다. 플러피뷰티의 실제 사진·영상과 확인된 정보만 사용했습니다.

카카오톡 등에서 링크를 공유할 때는 AI 연출 영상에서 눈을 뜨고 있는 장면(`ai-mood-film-preview-open-eyes.png`)이 보이도록 OG 미리보기 이미지를 지정했습니다. 같은 이미지를 영상 재생 전 포스터에도 사용합니다.
기존 카카오톡 미리보기 캐시와 구분되는 공유 주소는 `/share/`이며, 링크를 열면 홈페이지로 이동합니다.

## 현재 연결된 주소

- 상담: [플러피 스튜디오 카카오채널](https://pf.kakao.com/_fGKin)
- 인스타그램: [@fluffy_pmu](https://www.instagram.com/fluffy_pmu/)

## 메타 픽셀

픽셀 ID `1707051907661422`로 페이지 방문(`PageView`)을 기록합니다. 모든 링크·버튼 클릭은 `ButtonClick` 사용자 지정 이벤트로 기록하며, 버튼 이름·위치·연결 도메인을 함께 보냅니다. 카카오 상담 링크 클릭은 `KakaoConsultationClick`, 네이버 예약 링크 클릭은 `NaverBookingClick`으로도 따로 기록합니다. 이 두 이벤트는 **링크를 누른 사실**을 뜻하며 실제 상담 완료나 예약 완료를 뜻하지 않습니다.

## 공개 전 교체·확인

1. 최종 상호 표기: 노션은 ‘플러피뷰티’, 카카오채널은 ‘플러피 스튜디오’로 표기됩니다.
2. 헤어스트록 20만 원 이벤트의 적용 기간·포함 항목 및 네이버 리뷰 작성 방법. 원장님 전달 기준으로 리뷰 작성 조건과 선착순 20명을 반영했습니다.
3. 제공받은 원장 프로필·시술 포트폴리오 사진의 최종 선택과 공개 동의.
4. 주차 안내.
5. 검토가 끝나면 `index.html`의 `noindex, nofollow`를 제거하고 공유 미리보기 이미지를 추가합니다.

첫 화면에는 2026년 10월 8일 제공받은 김민선 원장의 실제 시술 영상을 사용했습니다. 모바일 호환성을 위해 H.264 MP4로 변환하고, 자동 반복 재생·음소거·화면 내 재생·정지 이미지 대체를 설정했습니다. 이전 AI 영상 표기는 실제 영상에 맞게 바꾸었습니다. 원장 소개에는 2026년 10월 5일 제공받은 손을 얼굴에 대지 않은 프로필 사진을, 포트폴리오에는 실제 눈썹 사진을 사용했습니다. 영어 세리프는 Cormorant Garamond, 한국어 제목은 Noto Serif KR, 본문은 Inter/Noto Sans KR로 구성했습니다. 후기는 출처 자료가 없어 넣지 않았습니다.

이전에 제작한 AI 분위기 영상은 상담 안내 다음의 별도 섹션에 다시 넣었습니다. 다른 본문 섹션과 같은 폭의 영상 아래쪽에 제목과 설명을 겹쳐 배치하고, AI 연출임을 작게 표시해 실제 시술 사진과 구분했습니다. 영상은 화면에 들어왔을 때만 재생되며 별도의 일시정지 버튼은 표시하지 않습니다.

영상 히어로는 ‘눈썹이 거기서 거기지~’라는 생각에 답하는 제목과 시술 선택의 중요성, 사진 상담 문구로 구성했습니다. 헤어스트록 20만 원 이벤트는 상담 버튼 위에 강조했습니다. 다음 **BEFORE YOU DECIDE** 섹션에는 ‘눈썹문신, 아직도 망설이고 계신가요?’로 시작하는 요청 문구 전체와 카카오 상담 버튼을 배치했습니다. 시뮬레이션의 예상 이미지와 실제 결과가 다를 수 있음을 안내합니다.

눈썹 시술 사진 9장은 클릭하면 큰 이미지로 열리는 갤러리로 구성했습니다. 좌우 버튼·키보드 방향키·모바일 스와이프로 넘길 수 있습니다. 바이브코딩 폴더의 실제 시술 장면 1장과 매장 사진 3장도 추가했습니다. 화면에 들어오는 요소의 등장 효과는 움직임 줄이기 설정을 존중합니다.
원장 사진 바로 아래에 김민선 원장 이름을 강조하고, 원장 소개와 눈썹 갤러리 아래에 카카오 상담 버튼을 배치했습니다. 각 섹션의 제목·설명·사진은 스크롤에 맞춰 차분하게 나타납니다.
정지은 브로우 참고 사이트의 이야기형 화면 흐름을 참고해, 영상 → 첫 고민 → 실제 눈썹 사진 → 고객 고민 → 이벤트 → 원장 소개 → 상담 과정 → 전체 갤러리 → FAQ → 매장 → 상담 순서로 재구성했습니다. 헤어스트록 20만 원 이벤트는 첫 화면, 중간 안내, 마지막 상담 영역에 보입니다. 원장님이 전달한 ‘네이버 리뷰 작성 시 · 선착순 20명’을 가격 아래에 명시하고 ‘헤어스트록이란?’ 설명을 추가했습니다. 강남권 50만~100만 원 비교와 ‘최고급’ 표현은 확인할 가격 자료와 객관적 기준이 없어 공개 문구에 넣지 않았습니다. 홈페이지 공유는 섹션 해시 없이 첫 화면 주소로 합니다.
